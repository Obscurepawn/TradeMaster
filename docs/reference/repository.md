# Repository and test map

The source indexes below link from a behavior to its implementation and regression tests. Paths refer to files maintained in this checkout. Local provider caches, DuckDB files, generated reports, compiler output and third-party study repositories are listed as exclusions in [.gitignore](../../.gitignore). Their contents depend on the machine and the selected run.

## Code and build boundaries

| Directory or file | Role |
|---|---|
| [python](../../python) / [trademaster](../../python/trademaster) | Python package root. [Package exports](../../python/trademaster/__init__.py) define the top-level imports. [contracts.py](../../python/trademaster/contracts.py) owns the data, factor, strategy and persisted-run contracts. [py.typed](../../python/trademaster/py.typed) declares installed type information. [Python rules](../../python/AGENTS.md) |

[File and test index](factors-and-strategies.md) |
| [backtest](../../python/trademaster/backtest), [engine snapshot module](../../crates/tm-engine/src/snapshot) | Published market snapshot, close-time decision API and daily target-portfolio execution. [Interface, files and tests](snapshot-backtest.md) |

[Workspace rules](../../crates/AGENTS.md) · [Rust implementations and tests](execution.md) |

Their integration suites live alongside them in [core tests](../../crates/tm-core/tests), [engine tests](../../crates/tm-engine/tests) and [runner tests](../../crates/tm-runner/tests).

## Guides, diagrams and examples

The [docs directory](..) contains the [documentation home](../README.md), which links runnable examples, operating guides and this [reference directory](.). The [command reference](commands.md) is organized by tool. The [architecture directory](../architecture) contains the [runtime walkthrough](../architecture/overview.md), the [saved-event workflow](../architecture/trademaster-overview.svg), the [separate inputs to strategy selection and factor evaluation](../architecture/trademaster-data-flow.svg), and [one session in the event runner](../architecture/trademaster-v1-architecture.svg). [Architecture documentation rules](../architecture/AGENTS.md)

The [examples directory](../examples) holds the [three-session input](../examples/round-trip.json), its [illustrated account history](../examples/round-trip.svg), the [TuShare strategy comparison](../examples/tushare-strategies.md), the [snapshot versus event run](../examples/rebalance-comparison.md), and its [daily closing equity chart](../examples/rebalance-equity.svg). The research guides cover [managed factors](../factor-management.md), [public factor sourcing](../public-factor-library.md) and the [full-market workflow](../full-a-factor-research.md). The [reviews directory](../reviews) records [which conclusions the historical factor study supports](../reviews/20260823-m9-full-a-quality-review.md).

The [fifteen-year ETF benchmark](../examples/broad-etf.md) uses [broad_etf_data.py](../../python/trademaster/e2e/broad_etf_data.py) to verify the index closes, ETF prices, opening limits and distribution dates. [long_history.py](../../python/trademaster/e2e/long_history.py) runs and times both strategies, saves their ledgers and checks replay. The [loader tests](../../tests/test_broad_etf_data.py) cover input validation, and the [benchmark tests](../../tests/test_long_history.py) cover strategy decisions, fees and the output files. The [original stock loader](../../python/trademaster/e2e/long_history_data.py) and its [input tests](../../tests/test_long_history_data.py) serve the [single-stock regression](../examples/long-history.md).

The [weekly all-A selection example](../examples/all-a-momentum.md) uses [prepare_all_a_snapshot.py](../../specs/examples/prepare_all_a_snapshot.py) to publish the daily market and [all_a_momentum.py](../../specs/examples/all_a_momentum.py) to rank stocks and run the ledger. The [market test](../../tests/test_prepare_all_a_snapshot.py) checks membership, price limits and corporate-action gaps. The [strategy tests](../../tests/test_all_a_momentum.py) check ranking, ties, missing observations, cash allocation and next-open execution.
