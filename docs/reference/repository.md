# Repository and test map

This map links each architectural boundary in the TradeMaster checkout to its implementation modules, crate and package rules, and regression test suites. Machine-local provider caches, DuckDB catalogs, generated report bundles, compiler build directories, and external study checkouts vary by environment and are excluded from version control via [.gitignore](../../.gitignore).

## Code and build boundaries

| Directory or file | Architectural role and ownership |
|---|---|
| [python](../../python) / [trademaster](../../python/trademaster) | Python package root: [__init__.py](../../python/trademaster/__init__.py) defines top-level public exports, [contracts.py](../../python/trademaster/contracts.py) declares shared data, factor, strategy, and run-artifact protocols, and [py.typed](../../python/trademaster/py.typed) advertises PEP 561 inline type annotations. [Python rules](../../python/AGENTS.md) |
| [data](../../python/trademaster/data), [research](../../python/trademaster/research) | Provider adapters, content-addressed Parquet object storage, DuckDB catalogs, and resumable full-market A-share panel construction and factor evaluation. [File and test index](data-and-research.md) |

## Guides, diagrams and examples

Under [docs](..), the [documentation home](../README.md) routes readers across runnable walkthroughs, operating guides, and this [reference directory](.), while the [command reference](commands.md) indexes every installed CLI and module entry point. Architectural behavior is illustrated in [docs/architecture](../architecture), which pairs the [end-to-end runtime overview](../architecture/overview.md) with diagrams of the [saved-event workflow](../architecture/trademaster-overview.svg), the [separation between strategy selection and factor evaluation](../architecture/trademaster-data-flow.svg), and [intraday event ordering inside one session](../architecture/trademaster-v1-architecture.svg) (governed by [architecture documentation rules](../architecture/AGENTS.md)).

Runnable walkthroughs and visual artifacts in [docs/examples](../examples) include the [three-session wire request](../examples/round-trip.json) and its [closing-balance timeline](../examples/round-trip.svg), the five-stock [Tushare strategy comparison](../examples/tushare-strategies.md), and the [snapshot-versus-event comparison](../examples/rebalance-comparison.md) with its [daily closing equity chart](../examples/rebalance-equity.svg). Research workflows are covered in the [managed factor guide](../factor-management.md), [public factor library guide](../public-factor-library.md), and [full-market A-share research walkthrough](../full-a-factor-research.md), complemented by [docs/reviews](../reviews) documenting [evidentiary boundaries of the published twenty-year factor study](../reviews/20260823-m9-full-a-quality-review.md).

Two multi-year and cross-sectional benchmarks connect verified data loaders directly to native snapshot execution:
- **Fifteen-year broad ETF benchmark.** Documented in [broad-etf.md](../examples/broad-etf.md), [broad_etf_data.py](../../python/trademaster/e2e/broad_etf_data.py) validates index closes, ETF bars, opening limits, and cash-distribution dates ([loader tests](../../tests/test_broad_etf_data.py)), while [long_history.py](../../python/trademaster/e2e/long_history.py) times and verifies both the moving-average strategy and buy-and-hold control ([benchmark tests](../../tests/test_long_history.py)). Earlier single-stock benchmarks use [long_history_data.py](../../python/trademaster/e2e/long_history_data.py) ([input tests](../../tests/test_long_history_data.py)) as described in [long-history.md](../examples/long-history.md).
- **Weekly all-A momentum selection.** Documented in [all-a-momentum.md](../examples/all-a-momentum.md), [prepare_all_a_snapshot.py](../../specs/examples/prepare_all_a_snapshot.py) publishes the market-wide daily snapshot ([market tests](../../tests/test_prepare_all_a_snapshot.py) verify exchange membership, price limits, and corporate-action gaps), and [all_a_momentum.py](../../specs/examples/all_a_momentum.py) ranks stocks and executes weekly rebalances ([strategy tests](../../tests/test_all_a_momentum.py) verify tie-breaking, missing observations, cash reservation, and next-open fills).
